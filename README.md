# aqorde organization profile

This repository contains the public profile shown on [github.com/Aqorde](https://github.com/Aqorde).

- [`profile/README.md`](profile/README.md) — public organization overview, in English with a Russian section.
- [`profile/assets/aqorde-logo.svg`](profile/assets/aqorde-logo.svg) — the approved aqorde logo.

The profile describes the platform's architecture, principles, and development stage.
It distinguishes the working single-companion prototype from planned voice,
avatar, and concurrent companion capabilities.
