**aqorde** is a platform in development for creating personal AI companions
with persistent memory, evolving personalities, and interchangeable language models.
We are building a foundation for companions that learn about you over time,
keep a shared history, and retain their identity when their underlying model changes.

## Built around Core

At the center of aqorde is **Core** - the persistent personality and memory kernel.
It owns the companion's identity, conversation history, long-term memory,
context, tasks, and permissions. The LLM provides reasoning and language;
Core maintains continuity across conversations and model changes.

- **Persistent memory** - conversations, important facts, preferences, and shared history.
- **A distinct personality** - character and behavior shaped within Core, with room to evolve.
- **Replaceable models** - the companion's identity and memory belong to Core, independently of the LLM.
- **A modular platform** - interfaces, skills, and tools connect around Core.
- **Local ownership and explicit control** — personal state stays local; external actions and cloud routes follow permissions.

## A home for different companions

**Lika** is the first companion growing within aqorde.
The platform is designed as a foundation for different companions,
each with its own personality, memory, and history.
Supporting several independent companions at the same time is part of that direction.

## Where we are

aqorde is in **early development**. The current single-companion prototype includes
local text dialogue, persistent history and memory, a Windows Studio interface,
and a private Telegram client.

We are developing document knowledge, research, tools, and user-controlled actions.
Voice, avatar experiences, and concurrent companion instances are planned extensions.
